# Mentor Workflow

## Core Principle

Mentor is an Obsidian-first research workflow. Durable outputs should become files, not remain only in chat.

## Modules

- Paper Ingestion
- Note Extraction
- Concept Indexing
- Literature Comparison
- Draft Revision
- Obsidian First

## Literature Reading Rules

1. Do not summarize the whole library at once; work in batches.
2. Default pilot batch size is 5 papers.
3. Read enough text to support each judgment before writing a note.
4. Separate author claims, text-based inference, and your evaluation.
5. Mark partial reads honestly.
6. Update indexes after each batch.

## Output Boundaries

- Literature-reading products go into the literature vault.
- Drafts, revision reports, reviewer responses, tables, and submission materials go into the paper-revision workspace.
- Do not mix execution files into the literature vault.

## Minimum Batch Deliverables

- updated `paper_inventory.csv`
- one `batch_xx` folder under `02_单篇笔记`
- one note per paper
- at least one concept card or comparison note when the material supports it
- updated navigation or index notes
